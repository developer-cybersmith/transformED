# Story 4-33 — Learner DNA Profile Quality Review

## Context

From Epic 3 and CLAUDE.md non-negotiable rules:
- Every `profile_text` must end with the DPDP Act 2023 disclaimer
- No IQ/EQ/SQ language in any profile text
- Raw numeric scores never returned to students
- `badge_labels` must be plain English
- Profile text should be 2–3 sentences, readable, encouraging tone

This story delivers an **automated quality checker** script that tests all existing
`learner_dna` rows in Supabase against the 5 quality criteria, producing a pass/fail report
with specific violations. It also provides a human review checklist for the 10-profile manual
review required by the tracker.

## Story

**As a** platform operator,
**I want** an automated quality check of all existing Learner DNA profile texts,
**so that** DPDP compliance, tone, and content rules are verified before real-student launch.

## Acceptance Criteria

### Automated checker
- [x] **AC 1.** `scripts/dna_profile_quality_check.py` reads all rows from `learner_dna`
  table (`.limit(500)` — BOUNDED) and evaluates each `profile_text` against 5 criteria.
- [x] **AC 2.** **Criterion 1 — DPDP disclaimer:** `profile_text` must end with (or contain)
  "This profile is generated by AI for personalization only. It is not a clinical or
  psychological assessment." Script flags FAIL if absent.
- [x] **AC 3.** **Criterion 2 — No banned terms:** `profile_text` and `badge_labels` must
  not contain: IQ, EQ, SQ, "intelligence quotient", "emotional quotient", "self-direction
  quotient", "clinical", "diagnostic", "disorder", "deficit", "intelligence test".
  Script flags FAIL with the offending term.
- [x] **AC 4.** **Criterion 3 — No raw scores:** `profile_text` must not contain standalone
  numeric scores like "score: 87" or "87/100" or "dimension score". Script warns on
  any numeric pattern matching `\b\d{2,3}(\.\d+)?(/100)?\b` within profile text.
- [x] **AC 5.** **Criterion 4 — Length check:** `profile_text` must be 50–800 characters
  (2–3 sentences target). Flag WARN if shorter than 50 (empty/stub) or longer than 800
  (may contain raw data dumps).
- [x] **AC 6.** **Criterion 5 — Badge labels plain English:** Each `badge_label` in
  `badge_labels[]` must not match the pattern `[A-Z]+:\s*\d` (e.g., "IQ: 87", "EQ: High").
  Script flags FAIL on any match.
- [x] **AC 7.** Script outputs a structured report: total profiles reviewed, pass count,
  fail count, warn count, and per-profile detail table (user_id truncated, criteria status).
- [x] **AC 8.** Script exits with code 0 if all profiles PASS, code 1 if any FAIL.

### Human review checklist
- [x] **AC 9.** `docs/dna-profile-quality-checklist.md` provides a 10-item manual review
  checklist covering: tone (encouraging, not clinical), diversity of profiles (6 distinct
  label names present), cultural sensitivity, no grammar errors, correct Spanish/Hindi/other
  transliteration if applicable.
- [x] **AC 10.** Checklist records results for ≥ 10 profiles (can be synthetic for now;
  real student profiles reviewed when data exists).

## Scale & Load

**Q1 — Unit:** One script run = one SELECT of all `learner_dna` rows + regex scanning.
Range: 0–500 rows (bounded by `.limit(500)`).

**Q2 — Fixed budgets:** Pure Python regex — no LLM calls, no external API. Fast: < 1s for
500 profiles.

**Q3 — Scope:** Per-deployment read (targets the Supabase project via env vars).

**Q4 — Unbounded:** `.limit(500)` bounds the read. If more than 500 real profiles exist
before calibration, the limit must be raised and re-derived. For Sprint 4 (0 real students),
500 is an adequate ceiling.

**Q5 — Inherited:** No inherited caps.

**Q6 — TOCTOU:** Read-only script — no mutations. No TOCTOU concern.

## Dev Notes

### DPDP disclaimer text (canonical)
```
"This profile is generated by AI for personalization only. It is not a clinical or psychological assessment."
```
Sourced from: CLAUDE.md ("Every `profile_text` value must end with the DPDP Act 2023 disclaimer")
and Epic 3 ("Legal disclaimer shown before onboarding").

### Badge label valid pattern
Plain English only: "Pattern Thinker", "Deep Diver", "Connector", "Builder", "Explorer",
"Achiever". NOT: "IQ: High", "EQ Score: 82", "Cognitive: 91".
