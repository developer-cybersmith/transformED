Critical Distinction: Subscription Credits ≠ API Credits

Common gotcha confirmed by multiple independent sources: Subscription plan credits (Free / Plus / Pro / Max) are for the web studio UI only. They cannot be used via the API. API billing is always pay-as-you-go per UTF-8 byte, completely separate from subscription tiers. A team buying the $100/mo Pro plan to use the API is paying for credits they cannot consume via API calls.

Sarvam vs Fish Audio for Indian content: Sarvam Bulbul v3 at ~$3.60/1M is ~4× cheaper than Fish Audio's $15/1M nominal rate. However, Fish Audio bills in UTF-8 bytes — Devanagari/Tamil are 3–4 bytes per character — so Fish Audio's effective rate for Indian language text is $45–$60/1M characters, making Sarvam 12–17× cheaper for Indic scripts. Sarvam is the correct choice for Hindi/Tamil/Telugu narration at any volume.
