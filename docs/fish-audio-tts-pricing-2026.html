Relevance to TransformED Stack

Current TTS stack: Sarvam AI Bulbul v2 → Azure TTS → Browser Speech (per CLAUDE.md). Fish Audio is NOT in the current stack. This pricing research is for evaluation purposes only.

If evaluating Fish Audio as a Sarvam replacement, key considerations:

  • The s2.1-pro-free free endpoint has no SLA — unsuitable for production without a paid plan.
  • Paid API at $15/1M bytes is pure pay-as-you-go with no subscription minimum.
  • No India-region endpoint confirmed — latency for ap-south-1 migration context needs verification.
  • Data residency: requests on the free tier may be used for model training; review DPDP Act 2023 implications for Indian student audio data before using.
  • The $3.00/lesson ceiling: at $0.015/1,000 chars, a 2,000-word narration script (~10,000 chars) costs ~$0.15 in TTS — well within budget headroom.
